# Thummapala Village

**Our Village. Our People. Our Future.**

A bilingual community website for Thummapala, built with React, TypeScript,
TanStack Start, and Vite.

## Development

Install Node.js and npm, then run:

```bash
npm install
npm run dev
```

## Verification

```bash
npm test
npm run build
npm run preview
```

## Production deployment

The project uses TanStack Start with Nitro and builds a Vercel deployment
through `.vercel/output`. Import the repository into Vercel and use the
standard `npm run build` command. Set the production domain before adding
absolute canonical and social-image URLs.
